# 👁 МНТК Eye-Microsurgery Bot (v2)

Telegram-бот для МНТК «Микрохирургия глаза»: следит за **мировой** научной литературой,
**переводит на русский**, **проверяет достоверность** (антифейк) и работает как
**AI-библиотека** (вопрос → ответ со ссылками).

## Что нового в v2

- **4 источника, весь мир:** PubMed + Europe PMC + **Crossref** (все DOI мира) +
  **CyberLeninka** (русскоязычные научные статьи, экспериментально).
- **Перевод через GPT:** иностранные статьи получают русский заголовок и русскую выжимку.
- **Антифейк-проверка:** ингест идёт только из научных индексов (новостных лент нет в
  принципе), плюс GPT-фактчекер отсекает ненаучное и сенсации (типа «учёные излечили
  близорукость»), помечает **уровень доказательности** и **громкие неподтверждённые заявления**.
- **Кнопки 👍 Сохранить и ↪️ Поделиться** под каждой статьёй + личный список `/saved`.

## Как работает антифейк

1. **Структурно:** данные берутся только из PubMed/EuropePMC/Crossref/CyberLeninka —
   это индексы научных работ, а не новостей. Crossref ограничен `type:journal-article`.
2. **Метаданные:** отозванные (retracted) статьи помечаются ⚠️.
3. **GPT-фактчекер:** каждая статья проверяется — научная работа или нет; не-научное
   отбрасывается, остальное получает бейдж достоверности:
   - 🟢 Высокий (мета-анализ/обзор, РКИ)
   - 🟡 Средний (наблюдательное)
   - 🟠 Низкий (клинический случай)
   - ⏳ Препринт (не рецензирован)
   - ⚠️ «Громкое заявление — требует подтверждения» (если выводы не подкреплены данными)

В дайджесте показывается счётчик: сколько найдено / новых / **отсеяно ненаучных/фейков**.

## Команды

| Команда | Что делает |
|---|---|
| `/start` | справка |
| `/digest` | собрать, проверить и прислать дайджест (топ по достоверности) |
| `/saved` | мои сохранённые статьи |
| `/stats` | размер базы |
| любой текст | вопрос к AI-библиотеке |

## Запуск локально

```bash
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env        # заполнить токены
python -m src.bot
```

Ключи: `@BotFather` (Telegram), OpenAI, email для PubMed/Crossref. Первый `/digest`
наполнит базу — после этого заработает Q&A.

## Деплой на Render

`render.yaml` настроен как worker (long-polling) с диском для SQLite. Залей репозиторий
на GitHub → Render → New → Blueprint → впиши секреты → Deploy. Диск требует платного плана.

## Честные ограничения

- **CyberLeninka** использует недокументированный эндпоинт и по умолчанию выключен
  (`ENABLE_CYBERLENINKA=false`); при включении формат полей может потребовать правки в
  `src/sources/cyberleninka.py`. Конвейер при сбое источника не падает.
- **eLibrary/РИНЦ** не подключён: нет открытого API. Русскоязычное покрытие идёт через
  Crossref/EuropePMC (индексируют часть рус. журналов) и CyberLeninka.
- **Перевод и фактчек стоят токенов OpenAI** — расход растёт с числом новых статей за день
  (регулируется `MAX_RESULTS_PER_TERM` и числом тем).
- Без диска на Render база обнуляется при перезапуске.

## ⚠️ Важно

Бот делает **обзор научной литературы**, а не медицинские рекомендации. Ссылки на
первоисточники прикладываются к каждой статье — проверяйте по ним.
